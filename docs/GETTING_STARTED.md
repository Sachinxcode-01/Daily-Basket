# 🚀 Developer Onboarding & Getting Started — Daily Basket

Welcome to the **Daily Basket** engineering team! This quickstart guide walks new engineers through codebase organization, architectural standards, and making their first pull request.

---

## 1. Quick Onboarding Checklist

1. Review [`docs/ARCHITECTURE.md`](ARCHITECTURE.md) to understand microservice architecture.
2. Review [`docs/GOOGLE_STITCH.md`](GOOGLE_STITCH.md) for UI/UX single source of truth rules.
3. Run `pnpm dev` locally to launch the NestJS API Gateway, Customer Web, Admin Dashboard, and Delivery PWA.
4. Launch the Flutter app using `cd apps/mobile && flutter run`.
