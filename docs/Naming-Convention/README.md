# Filesystem & Symbol Naming Conventions - Daily Basket

## 1. Backend (NestJS & Node.js)
- Files: `kebab-case.role.ts` (e.g. `auth.controller.ts`, `product.repository.ts`, `jwt-auth.guard.ts`).
- Classes: `PascalCase` (e.g. `AuthService`, `ProductRepository`).
- Methods/Variables: `camelCase` (e.g. `findProductById`, `stockQuantity`).

## 2. Flutter (Dart Mobile App)
- Files: `snake_case.dart` (e.g. `home_screen.dart`, `cart_provider.dart`, `product_details_page.dart`).
- Classes: `PascalCase` (e.g. `HomeScreen`, `CartProvider`).

## 3. Web (Next.js & React)
- Components: `PascalCase.tsx` (e.g. `ProductCard.tsx`, `Header.tsx`).
- Utilities/Hooks: `camelCase.ts` (e.g. `useCart.ts`, `formatPrice.ts`).
