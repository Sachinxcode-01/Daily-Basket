# 📞 Operations & Incident Escalation — Daily Basket

This document defines on-call responsibilities, incident severity classification, and escalation channels.

---

## 1. Incident Severity Levels

- **SEV-1 (Critical Outage)**: API down, payment failure, database corrupt. Response time: `< 15 mins`.
- **SEV-2 (Major Impact)**: Delivery GPS telemetry down, AI fallback active. Response time: `< 1 hour`.
- **SEV-3 (Minor Defect)**: UI styling drift, minor non-blocking bug. Response time: `< 24 hours`.
