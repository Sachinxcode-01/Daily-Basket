# 🛠️ Development Environment Setup — Daily Basket

This guide helps software engineers configure VS Code, Flutter SDK, Node.js, and pnpm monorepo tooling for development on Daily Basket.

---

## 1. Recommended VS Code Extensions

- **Flutter & Dart**: `Dart-Code.flutter`, `Dart-Code.dart-code`
- **Prisma ORM**: `Prisma.prisma`
- **TailwindCSS**: `bradlc.vscode-tailwindcss`
- **Prettier & ESLint**: `esbenp.prettier-vscode`, `dbaeumer.vscode-eslint`
